# СтройуниВЕРсал

Интернет-магазин строительных и отделочных товаров.

## Текущий статус

Начальный frontend-прототип: адаптивная главная страница, каталог демонстрационных товаров и страницы товаров. Это ещё не готовый интернет-магазин: оформление заказов, личный кабинет, админ-панель, сервер, база данных и ЮKassa будут реализованы следующими этапами.

## Стек

- React + TypeScript
- Vite
- React Router
- Lucide icons

## Запуск локально

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
```

## Важные замечания перед публикацией

- Цены, изображения и характеристики в демонстрационных карточках необходимо подтвердить у продавца.
- Контактные данные, реквизиты ИП, доставка, возвраты и юридические документы пока не заполнены.
- Не хранить API-ключи ЮKassa, пароли и другие секреты в репозитории.
- Платежи должны подтверждаться серверным webhook ЮKassa; фронтенд не должен самостоятельно отмечать заказ оплаченным.
